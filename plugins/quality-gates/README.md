# quality-gates

Stops work that would land broken.

- **PreToolUse** on Bash: `fallow-gate.sh` blocks commits and pushes when
  `fallow audit` returns a failing verdict. Generated by `fallow setup-hooks`.
- **Stop**: `verify-before-finish-gate.sh` blocks once per turn that changed code
  and ran nothing afterwards to check it.
- **Stop**: `lint-fallow-gate.sh` runs the project's lint command and
  `fallow audit` when the turn changed code or delegated to an agent, and
  blocks while either fails. Lint comes from the `lint` script in
  package.json, ruff, golangci-lint or cargo clippy; pin it in
  `.claude/quality.json` as `{"lintCommand": "...", "fallowCommand": "..."}`.
  It blocks again on every stop attempt, up to 5 in a row, so a loop that
  cannot fix the code still ends.
- **SubagentStop**: both gates, run on the subagent's own transcript.
- **SessionStart**: `verify-gate-session-reset.sh` clears the block counter.

Tests: `pnpm test`. Typecheck (syntax check of the shell hooks): `pnpm typecheck`.

# quality-gates

Stops work that would land broken.

- **PreToolUse** on Bash: `fallow-gate.sh` blocks commits and pushes when
  `fallow audit` returns a failing verdict. Generated by `fallow setup-hooks`.
- **Stop**: `verify-before-finish-gate.sh` blocks once per turn that changed code
  and ran nothing afterwards to check it.
- **SessionStart**: `verify-gate-session-reset.sh` clears the block counter.

Tests: `pnpm test`. Typecheck (syntax check of the shell hooks): `pnpm typecheck`.
